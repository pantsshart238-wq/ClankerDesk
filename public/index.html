Easiest — no GitHub needed. On this PC, open PowerShell in the ClankerDesk folder and run:

It walks you through making a free Cloudflare API token, uploads your own Worker, and writes the new address into config.json for you. Your agent keeps streaming the whole time.

ClankerDesk — how to use

This PC: — appears in the Devices dashboard. Friends connect with PIN

Accounts: the dashboard is private — each account sees only its own PCs. Click Sign up (free), copy your private key, put it into that PC's config.json as relayToken, restart ClankerDesk. The PC now belongs to your account.

From another device: log in (or use a shared link with ?device=…), pick a PC, enter its PIN. The PIN is shown in that PC's ClankerDesk window (or its Info page).

Get ClankerDesk for another PC:
download the setup bundle — unzip, run Setup.bat once, then Start-Agent.bat. Sign up if you don't have an account yet, paste your key into its config.json, and it shows up in your dashboard.

Sound: viewers hear whatever this PC plays — games, music, calls — automatically. Nothing to install: the agent listens to the Windows sound directly (no audio cable needed). A VB-CABLE is optional and only useful for the viewer mic below.

Mic: their mic plays into this PC so your games/Discord hear them (with a cable: set your mic input to CABLE Output). The sound pauses while a viewer talks so their own voice never echoes back. Ctrl+M in the viewer turns the mic on/off.

Buttons: 🔇 sound · 🎙️ talk · ⚙️ settings · 🎞️ quality · ⛶ fullscreen · 🔄 restart capture. Ctrl+L locks the mouse for games (Esc releases it). Ctrl+M turns the mic on/off.

Embedding: this page can be shown inside an iframe; add ?viewonly=1 to the address of embeds that should not be able to control the PC. The mic needs the embed to allow it — add allow="microphone" to the iframe, or open the link in its own tab to talk. Easiest: the Floating Window button on a device in your dashboard opens the viewer in its own window with the mic already allowed. The Install App button in the top bar installs ClankerDesk as a real app (own window, launcher icon — on a Chromebook it lands in the app launcher).
